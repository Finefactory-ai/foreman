# Contributing

Thank you for wanting to make Foreman better.

## Issues, not pull requests

Foreman does not take pull requests. This repository holds one commit per release, copied from
where Foreman is built, so a pull request here cannot be merged as it is.

[Open an issue](https://github.com/Finefactory-ai/foreman/issues/new/choose) instead:

- **A bug.** Use the bug form. It asks for the version, where Foreman runs and the output of
  `foreman doctor`, so a fix can start at once.
- **An idea.** Use the feature form. Say what you are trying to do and what gets in the way.
- **A fix you already wrote.** Paste the patch, or describe the change, in the issue. It will be
  built and tested where Foreman is made, and the changelog will name the fix.
- **A security problem.** Do not open an issue. Follow [SECURITY.md](SECURITY.md).
